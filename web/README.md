# 团队工作台 Web 原型（仅 Mock）

可点击的体验原型。所有账号和数据都是虚构的，只保存在浏览器本地存储里，不访问任何真实服务、密钥或网络。规格见 `docs/TEAM-WORKSPACE-WEB-PROTOTYPE.md`。这一版停在体验反馈，不接真实接口。

## 启动

```sh
node web/serve.mjs
```

然后打开 http://127.0.0.1:7420/ 。端口可用环境变量 `WEB_PORT` 修改。只监听 127.0.0.1，不需要安装任何依赖。

## 验收路线

1. 负责人建空间并邀请：以周宁登录，创建工作空间（只填名称，链接可选，没有分支），到「成员与接入」邀请 xu.an@example.test。切换为许安：在列表看到邀请，直接访问 #/w/<空间ID> 只看到无权限提示；接受之后才能进入。
2. 申请审批与拒绝：切换为陈默，用 ws_demo_pay 申请加入，只能看到待审批，直接访问空间地址仍被拒绝，重复提交提示已有申请。切回周宁，在「成员与接入」通过后，陈默可读概览和日志。在演示工具中恢复种子数据后重来一次并选择拒绝：陈默看到未通过且仍无访问权限，重新申请会复用同一条记录。
3. 阅读与接入：以林舟登录进入支付项目，在概览看成员、任务和最近变更，点击变更路径跳到日志正文。`specs/api-conventions.md` 里含脚本文字，应显示为普通文本而不执行。「连接 OpenCode」说明里没有仓库或分支校验，也没有额外确认。任务区域没有任何写操作。
4. 状态与隔离：切换身份后业务数据保留；退出、刷新后状态仍在；演示工具里设置「下一次读取/提交失败」，看到失败提示后重试成功；直接访问受限地址、新建的空空间都有对应的空态。用 Tab、Enter、Esc 走完主流程，把窗口缩到 860px 以下检查单列布局。在浏览器开发者工具的 Network 里只应看到本地文件。

## 自动检查

概览按「成员进展 → 只读分组任务行 → 最近变更」阅读，变更默认 5 条，
可展开完整记录；任务保留范围、持有者、更新时间和放弃原因，无拖拽或写操作。

工程日志使用纯文字折叠目录：五个根文件夹对应团队规范、规格、任务、成员进度、
活动；按路径显示子文件夹和文件名。Tab 到文件夹后用 Enter/Space 折叠或展开，
文件链接用 Enter 打开；深链接自动展开父目录。折叠状态仅在本次页面内保留，
不提供编辑、移动或删除文件操作。

成员与接入采用「成员管理 → 接入指南」两个全宽区域。姓名/邮箱合并，角色与
活跃时间保持可见；待审批仅在有申请时突出，邀请表单与等待接受的记录集中呈现。
参考仓库默认折叠，不参与接入。共享弹窗仍使用同一份占位符命令与复制反馈。

```sh
node --experimental-strip-types --test tests/web-*.test.ts
```

## 与现有后端的已知差异（体验确认后再讨论）

- 创建表单是「名称 + 可选参考链接，无分支」；现有创建接口要求至少一组仓库地址和分支。
- 登录后无需 key 即可读空间；真实接口用账号会话，空间读取用工作空间令牌，需要单独设计浏览器会话边界。
- 原型有独立的「未通过」状态；服务端拒绝目前记为 removed，成员侧也没有邀请或申请结果的专用列表。
- 日志目录来自 Mock 文件树；真实接入要先确认用哪些已有数据生成。
- Mock 里的行为选择：重复申请或重复邀请返回已有状态；已申请的账号被邀请时返回申请状态；有待接受邀请时再申请，返回邀请状态；演示数据接口里也限制了角色。
